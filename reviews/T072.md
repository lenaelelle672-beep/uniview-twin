# T072 Segments 批辅线

基线 `48d9e4c0ae30537017b6f578ac08af4a19149c39`。drei 仍是 10.7.9，没有新依赖。批线只给 DEMO / 图层的分区辅线，测距（T047）和人流（T048）仍走 drei `Line`。

## 行为

默认关。地址栏同步会先丢掉未知参数，所以 `?segments=1` 从启动导航 URL 回读，只在挂载时把图层写成开，之后以图层为准，可以再关掉，也不会把参数写回地址栏。按钮是 dock 晚加载后插入的「批线」，不进 `LayerPanel` 的行，避免改图层包哈希。

上限 `SEGMENT_LIMIT = 48`。超出的线段不交给 `<Segment>`，记在 `window.__twinSegments.dropped` 和按钮 title 上。子节点只挂在一个 `<Segments limit={48}>` 下面。端点变化走同一份 `LineMaterial`，不在 start/end 变化时 dispose；demand 下 `invalidate()` 再补一帧 `requestAnimationFrame`。关掉开关才卸载并 dispose。

总览是布局示意框（38 条，dropped 0）。单层有房间多边形时先画辅助十字，再画房间边；F12 实测 shown 48、dropped 66。B1 没有楼层 JSON，退回示意框，高度用 `floorSpec`，不用 JSON 里的 `meta.elevation_m`。

## 已知限制

- drei `Segments` 的 `useFrame` 在每次 demand 帧重写整段位置缓冲，自己不会 `invalidate`。这里只在端点签名变化时失效，不另加常驻循环。
- 不足 48 条时用零长度补齐，避免缩短后几何里留下旧坐标。补齐点和第一条起点重合，角上可能略重。
- 线宽走 `Line2` 着色器和 `onBeforeRender` 的 resolution，不是 ANGLE 线宽。
- 总览和 B1 是塔楼分区示意，不是测绘环。
- `SegmentObject` 不是 Three `Object3D` 子节点；真正画出来的是父级 `Segments` 上的一条 `Line2`。
