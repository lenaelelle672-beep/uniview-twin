## 做什么

总览和单层共用一份 0..1 爆炸目标。Stage 旁放原生 range，E 在收拢和完全展开之间切换，`[` / `]` 在 0、0.5、1 三档进退。楼层外壳仍走 `stepExplodeMotion`，工位仍走 `stepStationExplodeMotion`，两套时钟分开。滑杆拖动时这一帧落到目标，按钮和键盘仍用现有 0.8 秒 maath `cubic.out`。

`explodeProgress` / `setExplodeProgress` 只写在 `ViewSlice` 类型上。首屏初始对象不带这两个字段，dock 之后由 `installExplodeProgress` 装上，并包一层原来的 `setExploded`，所以爆炸按钮、视角释放和 `exploded` 布尔还是原来的 setter。大于 0 为展开，0 为收拢。目标记在 `globalThis.__ea`。没写过时布尔开关仍走到 1。`__es` 为真时时钟直接落到目标。

滑杆是 DOM range，挂在 `main.stage` 上，不进 drei `Html`，也不进 `Stage.tsx`。按键是 window keydown。输入框、抽屉和带 Ctrl / Alt / Meta 的组合键不抢。没有 `KeyboardControls`。没有新 npm。

进单层不会因为总览已经炸开就自动拆工位。只有动过单层滑杆、E / `[` / `]` 或工位按钮之后，工位时钟才跟随。离开单层会清掉这个跟随。

## 已知差距

- 楼层和工位写的是同一份进度。单层里拖过滑杆或按过键，回到总览会按这个数展开楼层。进单层本身不会拆工位。
- 单层里滑杆正聚焦时，Esc 只让滑杆失焦。刚用过滑杆、E / `[` / `]` 或工位按钮时，下一次 Esc 留在单层，再按一次才返回总览。搜索框、抽屉、测距和对焦仍先用原来的 Esc。
- 工位按钮按 `__ea` 改文案，写 DOM 放到下一帧动画回调，避免和视锥槽 flush 重入。`__twinView` 短暂缺失时沿用上一帧视图，不把跟随闩清掉。
- 停稳后空闲单层仍会把地面贴图、拾取树、着色器预编译和吊顶各自再交一帧。这些空闲 `invalidate` 先攒着，2.2 秒安静期结束再画一次，这道窗没有加长，也没有再引入 8 秒闩。作废的 `fab039c` 正式 QA 4/6：1024 夜 Δ=7（52→59），1366 夜 Δ=5（51→56）；1024 昼 Δ=0，1366 昼 Δ=0，1920 昼 Δ=3，1920 夜 Δ=1。上一轮只在持有已经是 0 时 `stop`，正式窗里持有还在，rAF 仍按画布速度画满。夜景在楼层和工位时钟已经不忙、又没有拖动时，告警、人物和飞入尾部的持有不再让空闲帧进入采样窗，rAF 收到终点只补一帧。昼景仍要等持有归零和 rest。按键、点击和滑杆仍立刻要帧。本地生产预览、SwiftShader、收拢后再堵 400ms、1.8 秒截止（非官方）：1024 昼 Δ=0，1024 夜 Δ=0，1366 昼 Δ=0，1366 夜 Δ=0，1920 昼 Δ=0，1920 夜 Δ=1。pageerror 0。这不是锁机绿。阈值仍是 Δ≤3。
- 滑杆和 E / `[` / `]` 跟 dock 一起，在首帧之后才出现。
- 单层滑杆在用户动手之前显示 0，即使总览已经展开。
- `window.__twinExplode.exploded` 仍表示「楼层运动已经停在 1」。半开时看 `progress`。按钮用的 store 布尔是进度大于 0。
- 镜头拉开和阴影烘焙仍看布尔，不看半开的比例。
- 越界楼层的错误文案收成「楼层序号」，少占首屏字节。
