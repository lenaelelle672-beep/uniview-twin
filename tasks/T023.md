# T023 D310 刀1：场地 CC0 PBR

基线：main `a88679a112671b64378a41bf0a899f9737cdb660`。只开 draft，不合入。

## 改了什么

四套 Poly Haven CC0 1k `nor_gl` + Rough，转 WebP quality 80，放在 `public/textures/ground/`。没有反照率，没有金属度，没有新 npm 依赖。

`src/scene/groundTextures.ts` 在 `window.__twinReady === true` 且 `window.__twinFirstFrameAt != null` 之后，再等一帧和一次 `requestIdleCallback`（超时 1200 ms），才用 `TextureLoader` 把 `normalMap` 和 `roughnessMap` 赋给 `grassMaterial` / `roadMaterial` / `pavingMaterial` / `sidewalkMaterial`。`RepeatWrapping`，`colorSpace = NoColorSpace`，赋完 `needsUpdate`，并打一帧 `window.__twinInvalidate`。昼夜颜色仍只走 `applySurfaceMode`。

道路和人行道的 `PlaneGeometry` UV 原是 0–1。合并后印成世界 `(x, -z)`，和挤出顶面同一套米制。草地、铺装沿用挤出 UV。`repeat = 1 / 物理边长`。

性能档各向异性为 1，其余为 4。

## 已知问题

- 法线槽从无到有会重编译场地 shader，发生在首帧之后。
- 总览机位很远，1k 法线会被 mip 平均，近处才看得清纹理。repeat 保持资产物理边长。
- `roughnessMap` 会乘上 `applySurfaceMode` 里的 roughness 标量。
