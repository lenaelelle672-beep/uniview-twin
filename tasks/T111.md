## 改了什么

- `src/scene/meshopt.ts`：在 `installMeshopt` 旁加 `uploadMeshoptDecoded(renderer, roots)`。收集网格后先让一拍，再交给 T089 的 `uploadGpuInBatches`：贴图一拍 1 张（1024² 带 mipmap），几何一拍 1 个网格（three 补丁里的 `uploadObject`）。一拍是 rAF 之后再等 `requestIdleCallback`（timeout 100ms；没有这个 API 时退回 32ms，和 `idleYield.scheduleIdle` 一样），两批不会落在同一帧。几处同时调用排成一队。
- `src/simready/mount.ts`：每个道具 `loadAsync` 解开、摆好之后先按拍上传，再进缓存、挂进场景。上传出错就留给首帧，照常挂。关掉再打开走缓存，不重复上传。`__twinSimReady.upload` 记四个道具的累计。
- `uploadMeshoptDecoded` 只给 dock 之后的 SimReady 独立分包用。`installMeshopt` 在首屏 index 里，vite 图里没有人 import 新函数，rollup 整段摇掉。测试锁住只有 `simready/mount.ts` 引用它。

SimReady 是仓库里唯一带贴图的 meshopt GLB：4 个文件 24 张 WebP，全是 1024×1024。屋面字、路灯、树、东立面、人物都没有贴图，首屏那几个也不在本单里动。
