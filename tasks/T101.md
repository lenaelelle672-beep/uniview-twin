# T101：SoftShadows（仅 balanced）

基线：`afde14f90364eeeae0a528ffcc075344e7fe85e1`（#101 合口证）。Draft PR。不合入。不改已合的 T098 / #101，不改场地贴图。

## 范围

drei `<SoftShadows samples={4} size={25} focus={0} />` 只在 `quality === 'balanced'` 挂上。perf 与 high 都不挂。0 新依赖，不升级 `@react-three/postprocessing`、`drei`、`three`。夜景 Bloom 仍只在 night。

## 改了什么

- `softShadowsQualityOn` 从 `quality !== 'perf'` 收成 `quality === 'balanced'`。高画质继续用 percentage PCF（2048），不把 `shadowMap.type` 打成 `BasicShadowMap`。
- samples 从 5 改为 4（规格 4 或 6）。size 25、focus 0 不动。
- `Scene.tsx` 不改。T090 生产构建会摘掉 Preload 接线，并要求剩下的 Scene 与 `38961417` 逐字节相同。晚窗口仍会在非 perf 把 `BalancedSoftShadows` 分包挂上；组件自己在 `quality !== 'balanced'` 时不渲染 drei `<SoftShadows>`，也不跑等待 rAF。perf 仍不进这道窗口。
- 挂载门闩不变：首帧之后 DemandLoop 至少一帧、D286 `shadowBakePending()` 为假；单层还要飞入停稳。门打开后再让出一帧才挂 drei，避免和烘影 / 飞入同帧。从 balanced 切到 high / perf 时同一轮渲染卸掉 `<SoftShadows>`，drei 把阴影类型写回去。
- 卸载仍由 drei 把 type 写回挂载时的值，组件再兜底：若仍是 `BasicShadowMap`，回到挂载前的类型。
- 夜景 `<NightBloom />` 仍是 `active && night`。白天不挂 Bloom。没有改 `balancedFx.tsx`。

## 本地测量

SwiftShader，`?q=` 钉住画质。均衡档挂上后 `samples === 4`、`size === 25`、`focus === 0`，随后 `shadowMap.type === 0`。白天没有 `__twinNightBloom`。切夜景后 Bloom 阈值 1.2，软阴影还在；切回白天 Bloom 戳消失。再切 high，软阴影戳消失，type 回到 1。冷启动 perf 不请求 `BalancedSoftShadows` / `balancedFx`。冷启动 high 会拉到分包，但不写 `__twinSoftShadows`，type 保持 1。console error/warning 0。
