# T012 第二阶段偏差清单

硬性项不在此列。F18 / F3 / F12 告警屏亮度比、色相、均衡档总览调用数按 D111 实测，不走偏差。

| 项 | 要求 | 现状 | 理由 |
|---|---|---|---|
| 地平线色带 | 可选，总览远景一条浅色地平线 | 未做 | 本阶段预算留给告警屏通道和切档空帧；补一条带要新增网格或改天空盒，收益只在远景。 |
| 贴图显存 | 方案第 8 节按档位上报贴图显存 | 测不到 | 验收机是 SwiftShader，`renderer.info.memory` 只有几何统计，没有贴图字节；浏览器也不暴露 GPU 显存。 |

其余 T012 第二阶段项按实测表交付。
