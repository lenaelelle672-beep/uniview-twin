## 过滤规则

`src/floors/labels.ts`：

- 丢掉非房间标注：`尾气|强电|弱电|送风|排风|…|门洞|常开|常闭|尺寸|卫生|厕所` 等机电/风口/电井。
- 丢掉卫生间符号与单字母：`女|男|P|N|W|p`。
- 丢掉纯数字/门洞尺寸、`N#电梯`、仅 `（常开）`。
- 优先级：电梯厅/前台/茶水/会议/洽谈/接待/大厅/展厅/食堂/休息/实验/主管办公/库房储藏/打印。
- 同名上限：会议室/洽谈室/茶水间 ≤2，其余 ≤1。
- 每层最多画 `MAX_ROOM_LABELS = 10`（给 officeDesks 和余量留调用）。
- 引线终点按外轮廓跨度 hex stagger + 斥力（span>70 → minSep 16，否则 7.2）。

## React key

- 房间 `id`：JSON `room.id`，缺省则 `room-${n}`（`parseRooms`）。
- 标签 id：`` `${plan.floorId}:${room.id}` ``（`roomLabelsFromPlan`）。
- React：`<Billboard key={label.id}>`，不用文案当 key。22 层 id 均唯一。
