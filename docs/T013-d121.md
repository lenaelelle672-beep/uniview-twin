## 过滤规则（D129）

`src/floors/labels.ts`：

- 只丢掉非房间标注：`尾气|强电|弱电|送风|排风|…|门洞|常开|常闭|尺寸|卫生|厕所` 等机电/风口/电井。
- 丢掉卫生间符号与单字母：`女|男|P|N|W|p`。
- 丢掉纯数字/门洞尺寸、`N#电梯`、仅 `（常开）`。
- **不再**按同名截断，**不再** `MAX_ROOM_LABELS = 10`。
- 优先级只影响排序，不影响条数。
- 引线终点按外轮廓跨度 hex stagger + 斥力，位移钳在锚点附近。

## BatchedText（D130 / D131 / D132）

- 直接用 `troika-three-text` 的 `Text` + `BatchedText`（不用 drei 的 BatchedText）。
- `troika-three-text` / `troika-three-utils` / `troika-worker-utils` 精确钉 **0.53.0**（`dependencies` + `overrides`）。lockfile 已解析副本全是 0.53.0；drei 声明仍是 `^0.52.4`，被 overrides 抬上来。
- 每层一个 `BatchedText`；成员 `sync` 后再 `batch.sync`；`visible=false` 直到 pack 完。
- 挂在 `FloorShell-${id}`（B1→B1）上，Y 取 `FloorInterior.position.y`，爆炸跟层走。
- 不做 Billboard / 不做多色。字面朝 +Z，双面绘制。
- `useWorker: false` + `disableTroikaCdnFallback()` 在创建任何 Text / BatchedText 之前调用（`textRuntime` / `BatchedRoomLabels` 模块顶）。
- `vite.config.ts` 的 `stubTroikaUnicodeResolver` 未改。升 0.53.0 后 rebuild：dist 里 `jsdelivr` **0**、`lojjic` **0**。
- 「嗆」编进 `characters`（字库没有这一字），实测外链 **0**，只请求 `/fonts/NotoSansSC-Regular-subset.woff`。
