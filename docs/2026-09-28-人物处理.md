## 处理方法
一键脚本：`assets/tools/scripts/build-people.sh`
1. `scripts/merge-people.mjs`：每个材质 baseColor → COLOR_0（线性色，VEC3）；删掉无贴图用的 TEXCOORD_0；全部 primitive 指向一个材质 `Character`（baseColor 白，metallic/roughness 取第一个材质）；`joinPrimitives` 合成 1 个 skinned primitive；`dedup → weld → prune`（prune 去掉了无网格、非骨骼、无动画的空节点：man/woman 各 11 个，human 7 个；骨骼数不变）。**未做 resample**：实测 resample 后动画姿态偏差约 0.9% 身高，而 Meshopt 已压缩动画，不 resample 文件反而更小。
2. `scripts/lod-people.mjs`：LOD1。`gltf-transform simplify` 在这些模型上**无效**（三角面数不变：FBX2glTF 法线接缝使顶点不共享，simplifier 卡住）。改用 meshoptimizer `simplifyWithAttributes`（Permissive + Prune + RegularizeLight，颜色+法线作为属性，颜色接缝 lock=2 保护），目标 780 面、误差上限 5%。只改索引，JOINTS/WEIGHTS 原样保留，蒙皮正常。meshopt 相对误差：man 0.0159、woman 0.0189、human 0.0079。
3. `npx gltf-transform meshopt <in> <out> --level high --quantize-color 12`（EXT_meshopt_compression + KHR_mesh_quantization，未用 Draco）。颜色用 12 bit（默认 8 bit 在深色上精度差）。
- 其他脚本：`probe.mjs`（统计）、`load-test-three.mjs`（加载+姿态对比）、`motion-check.mjs`（原地检查）、`anim-channels.mjs`、`validate.mjs`、`preview.html`。中间文件：`assets/work/people/`。

## 开发加载方式
- 必须用**本地** MeshoptDecoder，不走 CDN：
```jsx
import { useGLTF, useAnimations } from '@react-three/drei'
import { MeshoptDecoder } from 'three/examples/jsm/libs/meshopt_decoder.module.js'
const extend = (loader) => loader.setMeshoptDecoder(MeshoptDecoder)
const { scene, animations } = useGLTF('/models/people/man-in-suit.glb', false, false, extend)
// 多人同模型：用 SkeletonUtils.clone(scene)（three/examples/jsm/utils/SkeletonUtils.js），不要 scene.clone()
```
  （上面 drei 写法未在本机项目里跑过；Node 中 `GLTFLoader.setMeshoptDecoder(MeshoptDecoder)` 已实测可用。）
- 材质依赖顶点色：GLTFLoader 会自动设 `vertexColors: true`；若替换材质，新材质也要 `vertexColors: true`，baseColor 保持白色。
- **Walk/Run 是原地动画**，位移由代码驱动：实测 Walk 一个循环髋骨起止位移 man 0 / woman 0 / human 0.025（模型单位），Run 起止位移 0 / 0 / 0.015。
- 尺度：模型单位不是米。Idle 首帧蒙皮包围盒高度：man 4.806、woman 4.623、human 5.24。按身高 1.75 m 约需缩放 0.364 / 0.379 / 0.334。三者正面朝 +Z（渲染目测）。
- LOD 切换：精细/LOD1 骨骼名称、数量、动画完全相同，可用 drei `<Detailed>` 或按距离切换。
