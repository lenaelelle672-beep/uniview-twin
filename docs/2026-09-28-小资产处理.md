## 方法
一键：`assets/tools/scripts/build-props.sh` → `scripts/props-build.mjs`：`dedup → weld → prune → reorder → quantize(仅 NORMAL, 8bit) → EXT_meshopt_compression(high/FILTER)`，并声明 KHR_mesh_quantization。
