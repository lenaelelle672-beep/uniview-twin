## 要做
1. 单层视图走廊里 ≤ 12 个人沿预设折线走动（低模实例化，CC0 资产）。
2. 设备圆标：实例化平面 + 图标图集，悬浮在设备上方，朝向相机，按状态颜色 + 形状。
3. 房间标签：Line 引线 + Text（本地中文子集字体），≤ 30 个。
4. 接入楼顶标识、行道树、路灯 GLB（用 assets/ready/ 里处理后的版本），替换占位几何。标识按方案第 3 节贴南侧女儿墙立面靠西端；夜景 `sign_face` 白光、`sign_face_cn` 蓝光、`sign_body` 弱蓝自发光；路灯 `lamp_light` 夜景发光。

## 验收标准（均在 1366 宽度、`?q=balanced` 下判定，除非另注）
- [ ] F12 单层视图中能看到至少 6 个人在走廊里移动，不穿墙、不穿桌子（目测 30 秒）。
- [ ] 设备圆标四种状态都能在画面中找到，且形状不同。
- [ ] 会议室、茶水间、前台、电梯厅都有带引线的中文标签，文字无方块乱码。
- [ ] 楼顶 uniview 宇视 标识可见；行道树和路灯沿道路排列。
- [ ] 性能档下人物关闭，绘制调用仍 ≤ 100（总览）。
- [ ] 控制台 0 报错。
- [ ] 任务单末尾写明页面地址。

## 开发结果（开发填写）

页面：http://localhost:5190/?q=balanced&view=floor&floor=F12

- 单层走廊 12 人（Man in Suit / Woman Casual，性能档不生成、不请求 GLB），沿 layout 外推的折线走动。Walk 原地播放，位移和朝向由代码驱动。
- 工位电脑圆标一个 InstancedMesh：在线绿圆、空闲蓝方、告警红三角脉动、离线灰叉。位置只来自 `workstationPosition`。
- 房间引线标签用本地 `NotoSansSC-Regular-subset.otf`。标准层有会议室 1–3、茶水间、前台、电梯厅。
- 楼顶标识换成 v2（10,548 B），仍贴南侧女儿墙靠西端、字面朝南、底边与屋面齐平。夜间 `sign_body` 弱蓝自发光，不新增网格。未接入东侧格栅。

性能档总览绘制调用：改动前 71，改动后 71，增量 0（上限 +3，总上限 90）。
